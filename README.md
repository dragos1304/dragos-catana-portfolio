# dragoscatana.com

Source of [dragoscatana.com](https://dragoscatana.com), the site of Dragoș Catană, a freelance web designer and SEO specialist in Cluj-Napoca, Romania. Websites, SEO and AI visibility for clinics, law firms and local businesses.

- [English site](https://dragoscatana.com/en/)
- [Case study: Cheesy Media redesign](https://dragoscatana.com/en/work/cheesy-media/)
- [Free AI visibility audit (Romanian)](https://dragoscatana.com/audit-gratuit-vizibilitate-ai/)

Built with Next.js (static export), TypeScript and Tailwind CSS. `npm install`, then `npm run dev`; `npm test` runs the tests.
